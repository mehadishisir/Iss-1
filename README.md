# Biswas Agency

A simple, modern, and responsive agency service webpage built as part of a **Full Stack Web Development Internship** task.

The project demonstrates the basic workflow of building a responsive web interface using React and Tailwind CSS.

---

## 🌐 Project Overview

**Biswas Agency** is a simple digital agency landing page designed to showcase agency services, introduce the company, and provide a contact section for potential clients.

The main goal of this project is to practice the fundamentals of web development and create a basic structure that can be extended into a complete agency website in the future.

---

## ✨ Features

* Responsive header and navigation
* Mobile-friendly navigation menu
* Modern hero section
* Call-to-action buttons
* Three agency service cards
* About section
* Agency statistics section
* Contact information
* Contact form UI
* Responsive layout for desktop, tablet, and mobile
* Smooth scrolling navigation
* Hover effects and interactive UI elements
* Clean and modern dark-themed design

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/mehadishisir/Iss-1.git
```

### 2. Navigate to the project directory

```bash
cd biswas-agency
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 📱 Responsive Design

The website is designed to provide a smooth experience across different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

The navigation, content sections, service cards, and contact form adapt to smaller screen sizes.

---

## 📄 Website Sections

### 1. Header & Navigation

Includes the Biswas Agency logo, navigation links, and a call-to-action button.

### 2. Hero Section

Introduces the agency with a clear headline, short description, and project-related call-to-action buttons.

### 3. Services

The agency provides three core services:

* Web Development
* UI/UX Design
* Digital Solutions

### 4. About

Provides a short introduction to Biswas Agency and explains its approach to creating digital products.

### 5. Contact

Includes contact information and a contact form where users can enter their name, email, subject, and message.

### 6. Footer

Contains the agency name, short description, copyright information, and basic footer content.
